作业要求（课件 P49）：自己做实验，换数据集 / 换预训练模型 / 换 API。
本作业选「换预训练模型」：BERT-base → MacBERT → RoBERTa-4层，其余训练设置一字不改。

六级阶梯里本作业覆盖哪几级（课件 P6）：
    L0 规则      关键词表，秒级、可解释、0 数据；覆盖不全 → 只能兜底
    L1 传统 ML   分词 → df 过滤 → TF×IDF → 线性分类；强在数据封闭、可秒级重训
    L2 微调      预训练模型 + 池化 + 线性头；本体不动，只改池化和损失
    L3/L4        本作业没跑（本机无 API key、无 Qwen 权重），课件数字不能当自己实测

换模型这件事的成本：一个参数
    python bert/finetune.py --model bert-base     # 基线
    python bert/finetune.py --model macbert       # 换预训练任务/语料
    python bert/finetune.py --model roberta-l4    # 换成 1/12 大小的小模型

调参（四个旋钮来自课件 P22，比换模型更值钱）：
    参数	        说明
1	分层学习率	预训练层 2e-5、分类头 ×5：头是随机初始化的，要学得快
2	warmup + 衰减	前 10% 步数升温再线性降；直接大 lr 会冲掉预训练知识
3	类别加权	balanced。23× 不均衡，不加权时尾部类 recall 趋近 0
4	max_length	64。标题中位 20 字，32 与 64 实测差 <1 个点，截短省一半算力
5	池化	        cls / mean / max。Mean/Max 必须 mask 掉 PAD，否则补位零向量带偏统计量
6	换模型	        只改 --model，训练设置不动 —— 这样比较出来的差值才是「模型本身」的贡献

训练时盯着三个信号：
    现象	                        诊断	                        动作
val F1 第 1~2 轮到顶、第 3 轮回落	过拟合开始	                早停 / 减 epoch；不要看最后一轮硬撑
ECE 0.13~0.15（大模型）	        过度自信，conf 不能直接当阈值	温度缩放；低置信转人工/LLM 兜底
某两类互相吃掉最多	        标签口径重叠，不是模型没学够	做合并口径实验；确认是口径问题就改标签，别继续调模型
小模型 F1 低于 TF-IDF	        容量不够	                换回大模型；这个任务上小模型微调不划算
规则只命中 31%	                标题表述太多变	                规则只做兜底，别指望它提高覆盖

实测（同一批 500 条干净验证样本，seed=42，固定随机种子，3 epoch，batch 64，lr 2e-5，类别加权，AMP）：
    方法	                        参数量	准确率(含失败)	Macro-F1	ECE	训练耗时
    L0 规则 / 关键词	        —	0.192	        0.2734	        —	—
    L1 TF-IDF + SVM	        —	0.508	        0.4856	        —	10 s
    L2 MacBERT（max 池化）	102.3M	0.552	        0.5419	        0.144	517 s
    L2 BERT-base（max 池化）	102.3M	0.544	        0.5378	        0.140	517 s
    L2 RoBERTa-4层（cls）	8.8M	0.494	        0.4737	        0.082	60 s
    L2 RoBERTa-4层（mean）	8.8M	0.488	        0.4669	        0.085	58 s
    L2 RoBERTa-4层（max）	8.8M	0.490	        0.4684	        0.077	46 s
    （对照课件：规则 0.126、TF-IDF 0.509~0.513、BERT 0.534~0.556，量级一致）

三条结论：
    ① 换预训练模型：MacBERT 0.5419 vs BERT-base 0.5378，只差 0.4 个点 —— 落在 seed 噪声里。
       同一份配置不固定 seed 时两次跑出 0.5579 和 0.5419（差 1.6 点），固定后才稳。
       所以「换模型涨 1~2 个点」这种结论，单次实验不足为凭（课件也说瓶颈在数据/标签）。
    ② 换小模型是「掉 6~7 点、快 9 倍」的交易：8.8M 模型 50 秒训完，F1 约 0.47，
       比 BERT-base 低 6.5 点，还低于 TF-IDF（0.4856）→ 这个任务上小模型微调不划算。
    ③ 池化差异 <1 个点（cls 0.4737 / max 0.4684 / mean 0.4669），不要凭一次实验定；
       课件在 BERT-base 上是 Max > Mean > CLS（差 2.2 点），方向相反 →
       池化要「自己的模型 + 固定 seed + 多跑几次」再定。

错误分析（作业要求的「挑一组最容易混的」）：
    最易混：国际 ↔ 军事（12 条以上互错），其次 科技 ↔ 财经（11 条）
    合并口径实验（把两类合成一类后重算 Macro-F1）：
        MacBERT    国际+军事 0.5419 → 0.5624（+2.05）   科技+财经 0.5573（+1.54）
        BERT-base  国际+军事 0.5378 → 0.5533（+1.55）   科技+财经 0.5557（+1.79）
        TF-IDF     国际+军事 0.4856 → 0.5090（+2.34）   科技+财经 0.4932（+0.76）
    → 三种方法、两种合并全是正收益，说明是标签口径在打架，不是某个模型没学会。
    解决顺序：改口径（合并/写清判据）> 补可判别特征（下一周信息抽取）> 置信度闸门兜底 > 换更大模型。
